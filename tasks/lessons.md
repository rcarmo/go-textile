# Lessons

- Always update this file after any user correction or redirect, even if it is a short instruction (e.g., install a tool).
- When the user clarifies scope (e.g., do not vendor PHP library), acknowledge and avoid that path.
- Verify whether an existing library is already present in the workspace before searching externally.
- Prioritize reuse and code quality when user requests it; prefer refactors over ad-hoc fixes.
